# Responsive Landing Page

A modern and fully responsive landing page built using HTML and CSS. This project features a clean user interface with a dark theme and adapts smoothly across different screen sizes.

## Features

- Responsive Design
- Modern Dark UI
- Hero Section
- Navigation Bar
- Features Section
- Testimonials
- Newsletter Subscription
- Footer

## 🛠 Technologies Used

- HTML5
- CSS3

## Project Structure

```
responsive-landing-page/
│── index.html
│── style.css
```

## Getting Started

1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/responsive-landing-page.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
